# Promise Keeper

Customer promise ledger for Jira Service Management: kept, broken, due soon. Promise Keeper is an Atlassian Forge app.

When an agent tells a customer "I'll get back to you by tomorrow 3pm", Promise Keeper records that promise as a deadline. It fills the **Promised update by** field, lists open promises on the project's **Promises** page, posts an internal note about an hour before a promise is due, and marks each promise kept, kept late or broken when the next public reply goes out, or doesn't. A Rovo agent finds vague promises ("I'll get back to you soon") and sets a deadline once the agent confirms one.

Requires a Jira Service Management service project.
